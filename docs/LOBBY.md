# 大厅助手：基本功能待实测

大厅助手目前仅保留正常赛后返回、转让队长和自动接受三项基本功能。**三项自动操作均尚未完成真实游戏验证，不能视为稳定可用功能。** 默认示例配置全部关闭；已有个人配置中的三个开关保留原值。

本轮已移除头像校准、图像采集、文字识别、点击头像、跳过结算及卡加载恢复。客户端结算卡住时请手动处理，不再尝试坐标或控件点击。不会选英雄、开始匹配、重启客户端或强制退队。

## 基本行为

- **正常赛后返回**：仅在 `EndOfGame` 阶段、游戏进程退出至少 2 秒、赛后延迟到达后提交一次返回请求。等待统计或结算前流程时不提前请求，不跳过结算。以回读到组队房间确认结果。
- **转让队长**：本人是队长且大厅稳定后，选择可接任队友；可指定队友，其不在房间时等待。只有回读到选定队友成为队长才确认转让。
- **自动接受**：仅处理当前有效、本人未响应且客户端未隐藏的就绪确认。手动拒绝或已接受时不覆盖用户操作；回读本人已接受或进入英雄选择才确认。

## 请求结果

界面区分未执行、已提交待确认、明确拒绝和结果不确定。HTTP 请求被拒绝不显示“正在返回”，之后手动进入房间也不冒充自动成功。超时只回读，不循环重发。后续轮询保留已知失败状态。

动作记录在请求前原子领取，保存在 `runtime/lobby-actions.json`，仅含加盐摘要、计数和时间；不保存认证参数或玩家名。重连、暂停和重启保留去重，记录损坏时停止新动作，不删除记录来强行重试。

## 权限与启动

国服客户端可能以管理员权限运行且 `lockfile` 为空，普通权限工具因此无法读取连接参数。大厅页会说明权限差异，提供用户主动的管理员重启，也可使用 `start-admin.cmd`。

重启前清理旧任务，Windows 标准授权后新窗口保持暂停，只读检查连接；需要手动点击“继续监测”才开始自动操作。取消授权保留原窗口。读取当前房间只查询状态，不接受、转让或返回。

## 配置

```json
{
  "lobby_auto_return": false,
  "lobby_auto_promote": false,
  "lobby_auto_accept": false,
  "lobby_accept_delay": 1.0,
  "lobby_return_delay": 3.0,
  "lobby_preferred_member": ""
}
```

接受延迟范围 0–10 秒，赛后返回延迟 0–30 秒，与死亡学习的两项时间设置独立。保存后即时生效，旧任务取消；全局暂停和退出停止大厅线程。

旧 `lobby_recover_client`、`lobby_stuck_seconds` 字段在配置迁移时退役，不会重新开启已删除功能。其他用户字段和死亡学习参数保留，原有校准文件不主动删除，但不再读取或使用。

## 验证状态

模拟测试已覆盖请求拒绝、超时、状态确认、权限差异、去重、暂停、指定队友和旧配置兼容。此前已完成真实客户端只读连接，**没有据此证明三项自动操作可用**。

本轮用户选择暂缓真实游戏测试，受控测试未发送任何实际操作请求。真实接受、转让和正常赛后返回继续标为待实测；日后仅保留真实通过的项目。死亡学习与娱乐核心独立运行。
