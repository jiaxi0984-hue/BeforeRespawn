# LOL-Words-zhandoushuang · 泉水时间管理大师

活着战斗爽，倒了背词忙。

阵亡自动切学习，想摸鱼也能刷会儿视频；复活前准时回岗——人可以倒，时间不能白送。

**死亡达到一定数量之后将会收到严厉的惩罚!不准坑我!!😡**

## 当前功能

在英雄联盟死亡等待期间使用自己选择的学习软件，或在专用浏览器窗口中查看哔哩哔哩、抖音。学习与娱乐共用本人死亡判断、切出延迟、灰屏保护、置顶和复活返回；对局结束不关闭目标。

- **学习模式**：默认 Anki；可自动发现已安装软件、通过文件选择添加自定义桌面软件，或搜索学习官网。配置精确启动命令、进程路径、窗口标题/类名和目标置顶开关。
- **娱乐模式**：哔哩哔哩官网或抖音官网，首次满足安全切出条件才创建专用 Edge/Chrome 窗口，后续复用。不会覆盖日常标签页。
- **目标复用**：整个工具运行期间，每个目标自动启动最多一次。用户关闭后不循环启动，可手动重新打开；暂停和下一局不重置启动预算。
- **可靠窗口识别**：桌面软件使用完整进程路径和窗口条件；浏览器使用本工具创建的进程身份、创建时间、专用配置目录及页面标识。多个窗口无法唯一匹配时拒绝随意选择，已锁定窗口关闭后也不自动改选其他窗口。

## Windows 桌面界面

采用“轻量游戏伴侣风”的 PySide6 原生桌面界面：运行首页、学习目标、娱乐目标、通用设置、运行日志五个页面。顶部横向导航保留五个页面；首页使用流程与目标双栏，提示当前死亡处理阶段。顶栏始终显示监测状态与暂停操作；目标状态、死亡流程、窗口返回结果分别呈现。扫描与查询在后台执行，空结果、网络失败和窗口匹配不唯一都有对应提示。

## 安装与启动

环境：Windows 10/11 64 位，**Python 3.14（64 位）**。界面使用 PySide6-Essentials 6.12.0；旧界面回归测试另需 Python 附带的 Tk。网页目标另需已安装 Edge 或 Chrome。Anki 或其他桌面学习软件由用户自行安装。

```powershell
git clone https://github.com/jiaxi0984-hue/LOL-Words-zhandoushuang.git
cd LOL-Words-zhandoushuang
```

源码安装：双击 `install.cmd`，将锁定依赖安装到项目 `_deps`；再双击 `start.cmd`。交付的运行压缩包已经包含 `_deps`，可跳过依赖安装，但仍需本机 Python 3.14。

先退出旧工具，解压到独立目录，避免两个版本同时监测。首次进入工具默认学习模式、Anki、死亡后延迟 3 秒、复活前提前返回 1 秒、无边框、维持置顶开启。

## 学习目标与官方支持核实

“检测学习软件”通过持久的软件库匹配本机安装登记、应用路径登记、开始菜单和桌面快捷方式、运行进程及 Anki 常见目录，优先列出学习应用。支持名称过滤和查看未检测到的目录项目；实际找到的程序可直接选择使用。已有自定义学习目标也会检查并显示。找不到时仍可用文件选择器添加。

首批内置 **17 个名称条目，其中 11 类已核实 Windows 客户端**，不是市场全量清单；目录和来源见 [CATALOG.md](docs/CATALOG.md)，数据文件为 `learning_catalog.json`。只使用实际找到的程序路径，目录不预设或虚构本机安装位置。

自定义桌面软件以参数数组启动，不经命令行外壳。先匹配精确进程路径，再匹配标题包含条件和类名；共享 Python/Java 等解释器时还必须配置窗口条件。使用启动器的软件可能需要把启动程序和实际进程路径分别配置。具体软件适配效果需单独验证。

## 共用死亡保护

1. 通过固定的 `https://127.0.0.1:2999/liveclientdata/` 接口严格匹配本人。前台变化不停止死亡与复活监测。
2. 存活时建立彩色参照，死亡后连续确认两帧有效灰屏。全黑、过暗、采样失败、缺少参照均不等于灰屏；不单凭倒计时推测死歌、大嘴、赛恩的操作阶段结束。
3. “死亡后切出延迟”默认 **3 秒**，可设为 5 秒或 0–120 秒内其他值。延迟与灰屏都满足，才启动和显示目标。
4. 确认灰屏前手动切走时，延迟到达后短暂恢复游戏，等待至少 0.3 秒重绘，再确认新画面。最多恢复 3 次，间隔至少 2 秒；失败则继续等待或跳过，不猜测后台灰屏。
5. 同次死亡已确认的灰屏证据可跨手动切屏保留。接近提前返回门槛前 0.5 秒内不再发起新的切出；倒计时为零不切出。提前复活、对局结束、暂停或接口失效时取消过期切出。
6. 复活前最小化目标并恢复游戏；必须同时确认游戏实际在前台、目标遮挡已消失才报告返回成功。返回重试最多约 3 秒。
7. 置顶每 0.5 秒维护窗口层级，不持续激活窗口。返回、暂停、退出、对局结束、模式切换时恢复目标原有置顶偏好。全屏兼容路径会先最小化游戏，无边框优先直接显示目标。

修改并保存后：模式、目标立即切换，取消旧模式的本次死亡切出，等待下一次完整死亡；显示方式立即生效；公共计时、灰屏阈值、全局置顶参数需暂停并恢复监测后生效。暂停快捷键为 **Ctrl + Alt + F8**。

## 专用浏览器的边界

使用本工具自己的 `runtime/browsers/` 配置目录、随机回环调试端口和应用窗口；不接入日常浏览器、不读取其密码、Cookie 或浏览历史。可以在专用窗口内自行登录，工具不会读取登录凭据；浏览器自身可能在专用目录中保存网站数据，因此该目录不要分享。

关闭专用窗口后不反复新建，需手动重新打开。网站登录、验证码、视频播放、自动播放限制和下载确认由用户处理；本工具只负责显示窗口，不承诺自动播放。浏览器策略、权限或多个窗口造成无法可靠识别时停止操作，不按浏览器名称猜测窗口。

当前 **281 项自动化测试通过**，包含状态隔离、跨局清理、名称解析、官网候选过滤、软件库检测、配置迁移、窗口管理、权限差异与管理员重启门控、模拟下载及目录迁移后的入口 / 资源验证。没有在测试中下载实际安装包。

```powershell
python -B -m unittest discover -s tests -v
python -m lol_words --check
python tools/check_target_window.py
python tools/check_browser_readonly.py
```

功能检查覆盖如下，测试环境与实际可用边界分别标明：

| 功能 | 本轮检查与边界 |
|---|---|
| 本人死亡、延迟、灰屏与复活返回 | 模拟正常 / 短死亡、接口中断、手动切屏、黑屏、被动阶段与任务取消；缺少有效复活倒计时不再按 0 秒处理 |
| 学习软件发现与自定义目标 | 名称库、真实路径、无安装、多窗口、手动关闭、不重复启动有回归；本机只读实际找到 Anki、Obsidian；不能承诺所有品牌软件都已适配 |
| 官网名称查询 | 内置目录命中、待确认候选、歧义、无结果、网络失败有模拟覆盖；未对每个网站的登录和学习流程实测 |
| 浏览器页面复用 | 独立浏览器身份及本地测试页重复读取通过；未访问个人浏览器资料，不代表每个娱乐网站的媒体行为均已实测 |
| 持续置顶、异步返回、无边框遮挡 | Windows 临时进程实际检查通过；全屏 / 无边框、连续右键与特定英雄仍需真实游戏逐项验证 |
| 目标手动打开 | 已修复进程启动但主窗口未就绪时过早报告失败的问题，保留启动等待与超时提示 |
| 配置、暂停、切换与退出 | 迁移、原子保存、非法结构、不覆盖原文件、旧任务取消均有回归；已删除功能的旧字段不再生效 |
| 下载与外部依赖 | 下载仅使用模拟入口，不实际获取或运行安装程序；网页模式需本机安装 Edge 或 Chrome |

本轮未操作真实英雄联盟对局，不将模拟或替身窗口结果当作真实对局通过。

日志只记录状态变化与必要诊断，不上传画面、卡片或浏览历史。请勿提交 `runtime/`、个人 `config.json` 或 `runtime.log`。
