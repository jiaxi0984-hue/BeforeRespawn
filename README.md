# LOL-Words-zhandoushuang · 泉水背词

我要背单词,可是我又要玩海斗战斗爽怎么办?怎么办呢?

为您提供以下功能（以下四项为计划功能，当前版本尚未实现）：

1. 对局结束了自动返回大厅
2. 自动转让房主（这样不当房主的话，就可以完全解放双手）
3. 自动接受游戏
4. 自动选瘤子英雄

这样的话，就只需要战斗和学习了

## 当前可用

在英雄联盟死亡等待期间复习 Anki：进入对局自动打开 Anki，确认死亡灰屏后临时置顶，复活前返回游戏，对局结束正常关闭。

面向 Windows，针对海克斯大乱斗场景开发。采用本地对局数据与画面双重确认，支持无边框、全屏和自动兼容切换。当前未按游戏模式限制触发，其他模式的表现需单独验证。

## 功能

- **自动定位 Anki**：检查运行进程、安装信息、快捷方式和各磁盘常见软件目录，不必填写安装路径。
- **自动识别对局**：大厅、加载和实际对局分开处理；进入对局打开或复用 Anki，结束后正常关闭，持续等待下一局。
- **死亡灰屏双重确认**：识别本人死亡，再与存活时的彩色画面比较，连续确认灰屏后切换。
- **临时置顶与焦点管理**：恢复 Anki 窗口并置顶，返回或暂停时恢复原置顶状态。
- **可靠返回判定**：同时检查游戏已取得前台、Anki 已隐藏或最小化；不会把无边框的焦点回跳直接当作返回完成。
- **有限返回重试**：窗口恢复较慢时保留返回任务，最多重试约 3 秒，成功立即停止；游戏接口短暂不可用时仍会继续。
- **往返测试**：点击“测试往返（3秒）”，不必等待死亡即可检查窗口切换。
- **本地日志**：记录对局状态、触发条件与返回结果，不保存卡片或截图，不上传日志。

## 环境要求

- Windows 10 或 Windows 11，64 位。
- **Python 3.14，包含 tkinter**。当前锁定依赖和本机验证均使用该版本。
- 已安装的 [Anki 电脑端](https://apps.ankiweb.net/) 与英雄联盟。

本项目不是独立的免安装可执行文件。源码仓库不包含 Python、Anki、游戏、下载后的依赖或个人运行配置。

## 安装与运行

```powershell
git clone https://github.com/jiaxi0984-hue/LOL-Words-zhandoushuang.git
cd LOL-Words-zhandoushuang
```

1. 安装 [Python 3.14](https://www.python.org/downloads/)；使用官方安装程序的默认 tkinter 组件。
2. 双击 `install.cmd`。脚本将依赖安装到项目内 `_deps`，并记录本机解释器位置，不修改系统 Python 包。
3. 双击 `start.cmd`。程序自动开始监测，不需要每局点击开始。
4. 确认工具中的显示方式与游戏设置一致。选择显示方式后立即生效。
5. 进入实际对局后 Anki 自动打开。自行选择牌组、进入复习，再切回游戏。

如果需要从终端安装：

```powershell
py -3.14 -m pip install --only-binary=:all: --target _deps -r requirements.txt
py -3.14 app.py
```

首次没有 `config.json` 时读取 `config.example.json`；运行后保存个人设置到被 Git 忽略的 `config.json`。

## 显示方式

| 选项 | 死亡时 | 返回游戏时 |
|---|---|---|
| 无边框 | 优先直接置顶 Anki，必要时才切出游戏 | 最小化 Anki，确认游戏取得前台且遮挡消失 |
| 全屏 | 先最小化游戏，再显示 Anki | 最小化 Anki，等待游戏窗口实际恢复 |
| 自动兼容 | 采用保守的全屏兼容路径 | 与全屏兼容方式一致 |

工具不会修改英雄联盟的画质或视频配置文件。

## 默认设置

| 设置 | 默认值 |
|---|---|
| 显示方式 | 无边框 |
| 复活前返回 | 1 秒 |
| 画面灰色占比门槛 | 82% |
| 连续确认次数 | 2 次 |
| 采样间隔 | 0.2 秒 |
| 返回重试上限 | 约 3 秒，成功即停止 |

显示方式立即生效，其他参数修改后需暂停并恢复监测。死歌、大嘴、赛恩没有被整体排除；“灰屏”是否准确对应其操作阶段结束，仍需实测。纯黑、过暗或无法采集的画面不能当作可靠灰屏证据。

## 暂停与 Anki 管理

- **Ctrl + Alt + F8** 或“暂停”：停止监测、清理临时置顶并尝试恢复游戏。
- “恢复自动监测”：继续等待游戏和下一局。
- “重新自动查找”：重新定位已移动的 Anki。
- 默认对局结束时也会关闭已复用的 Anki。勾选“保留对局开始前已经打开的 Anki”可保留自行预先打开的窗口。
- 关闭 Anki 使用正常窗口关闭请求；同步或确认对话框可能需要手动处理，不会强制结束进程。
- 对局中自行关闭 Anki，本局不会反复打开，下一局再尝试启动。
- 暂停或退出工具会保留 Anki。首次仍需自行打开工具，没有设置 Windows 开机启动。

牌组选择、翻卡、评分等学习操作由用户完成；程序不自动答题或修改卡片。

## 实现与文件

```text
app.py              中文界面、自动监测和流程协调
automation.py       对局生命周期与 Anki 启停
presentation.py     临时置顶、焦点保护和返回状态管理
native.py           Windows 进程与窗口接口
game_api.py         本地对局数据接口
capture.py          DXGI 采样与 GDI 回退
core.py             死亡、身份匹配和灰屏判断
discovery.py        Anki 自动查找
tests/test_app.py   自动化测试
tools/              只操作临时窗口的手动系统验证
```

游戏状态从固定的 `https://127.0.0.1:2999/liveclientdata/` 读取。仅该本地自签名连接接受证书例外，不使用系统代理，不跟随重定向。画面采样仅在游戏前台时执行，返回中央区域的小尺寸像素用于判断；不保存或上传截图。程序不读写游戏进程内存。

## 测试

安装依赖后运行：

```powershell
py -3.14 -m unittest discover -s tests -v
```

当前包含 **107 项测试**，覆盖死亡与灰屏判断、身份匹配、自动开关 Anki、连续对局、接口故障、延迟返回、焦点回跳、遮挡消除和模式切换。

本机窗口验证（会创建两个临时窗口，检测到实际对局时跳过）：

```powershell
py -3.14 tools/check_async_return.py
py -3.14 tools/check_borderless_return.py
```

启动和采样检查不会启动游戏监测、打开或关闭 Anki：

```powershell
py -3.14 app.py --check
```

模拟数据和临时窗口检查不能替代真实英雄联盟对局验证。显卡、显示模式、权限、窗口管理和游戏版本变化都可能影响切换效果；不承诺所有环境下可用。

## 故障反馈

复现前确认游戏与工具的显示方式一致，先使用“测试往返（3秒）”。反馈时说明 Windows、Python 版本、显示方式、是否单/多显示器以及实际行为。需要分享 `runtime.log` 时，先删除本机路径、玩家标识等不希望公开的内容；不要上传完整的个人配置、Anki 数据库或账号信息。
