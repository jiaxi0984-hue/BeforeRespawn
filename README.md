# LOL-Words-zhandoushuang · 泉水背词

我要背单词,可是我又要玩海斗战斗爽怎么办?怎么办呢?

为您提供以下功能（以下四项为计划功能，当前版本尚未实现）：

1. 对局结束了自动返回大厅
2. 自动转让房主（这样不当房主的话，就可以完全解放双手）
3. 自动接受游戏
4. 自动选瘤子英雄

这样的话，就只需要战斗和学习了

## 当前功能

在英雄联盟死亡等待期间使用自己选择的学习软件，或在专用浏览器窗口中查看哔哩哔哩、抖音。学习与娱乐共用本人死亡判断、切出延迟、灰屏保护、置顶和复活返回；对局结束不关闭目标。

- **学习模式**：默认 Anki；可自动发现已安装软件、通过文件选择添加自定义桌面软件，或添加学习网页。配置精确启动命令、进程路径、窗口标题/类名和目标置顶开关。
- **娱乐模式**：哔哩哔哩官网或抖音官网，首次满足安全切出条件才创建专用 Edge/Chrome 窗口，后续复用。不会覆盖日常标签页。
- **死亡惩罚**：默认关闭。只在娱乐模式开启后，本人单局累计死亡 ≥20 次，在安全切出时优先展示原神官网，尝试点击一次官方 Windows 下载入口。不会运行下载文件或安装程序。
- **目标复用**：整个工具运行期间，每个目标自动启动最多一次。用户关闭后不循环启动，可手动重新打开；暂停和下一局不重置启动预算。
- **可靠窗口识别**：桌面软件使用完整进程路径和窗口条件；浏览器使用本工具创建的进程身份、创建时间、专用配置目录及页面标识。多个窗口无法唯一匹配时拒绝随意选择，已锁定窗口关闭后也不自动改选其他窗口。

当前版本未增加自动接受游戏、转让房主、选择英雄或自动返回大厅。

## 安装与启动

环境：Windows 10/11 64 位，**Python 3.14（含 tkinter）**。网页目标另需已安装 Edge 或 Chrome。Anki 或其他桌面学习软件由用户自行安装。

```powershell
git clone https://github.com/jiaxi0984-hue/LOL-Words-zhandoushuang.git
cd LOL-Words-zhandoushuang
```

源码安装：双击 `install.cmd`，将锁定依赖安装到项目 `_deps`；再双击 `start.cmd`。交付的运行压缩包已经包含 `_deps`，可跳过依赖安装，但仍需本机 Python 3.14。

先退出旧工具，解压到独立目录，避免两个版本同时监测。首次进入工具默认学习模式、Anki、死亡后延迟 3 秒、复活前提前返回 1 秒、无边框、维持置顶开启，死亡惩罚关闭。

## 共用死亡保护

1. 通过固定的 `https://127.0.0.1:2999/liveclientdata/` 接口严格匹配本人。前台变化不停止死亡与复活监测。
2. 存活时建立彩色参照，死亡后连续确认两帧有效灰屏。全黑、过暗、采样失败、缺少参照均不等于灰屏；不单凭倒计时推测死歌、大嘴、赛恩的操作阶段结束。
3. “死亡后切出延迟”默认 **3 秒**，可设为 5 秒或 0–120 秒内其他值。延迟与灰屏都满足，才启动和显示目标。
4. 确认灰屏前手动切走时，延迟到达后短暂恢复游戏，等待至少 0.3 秒重绘，再确认新画面。最多恢复 3 次，间隔至少 2 秒；失败则继续等待或跳过，不猜测后台灰屏。
5. 同次死亡已确认的灰屏证据可跨手动切屏保留。接近提前返回门槛前 0.5 秒内不再发起新的切出；倒计时为零不切出。提前复活、对局结束、暂停或接口失效时取消过期切出。
6. 复活前最小化目标并恢复游戏；必须同时确认游戏实际在前台、目标遮挡已消失才报告返回成功。返回重试最多约 3 秒。
7. 置顶每 0.5 秒维护窗口层级，不持续激活窗口。返回、暂停、退出、对局结束、模式切换时恢复目标原有置顶偏好。全屏兼容路径会先最小化游戏，无边框优先直接显示目标。

修改并保存后：模式、目标和惩罚开关立即切换，取消旧模式的本次死亡切出，等待下一次完整死亡；显示方式立即生效；公共计时、灰屏阈值、全局置顶参数需暂停并恢复监测后生效。暂停快捷键为 **Ctrl + Alt + F8**。

## 专用浏览器的边界

使用本工具自己的 `runtime/browsers/` 配置目录、随机回环调试端口和应用窗口；不接入日常浏览器、不读取其密码、Cookie 或浏览历史。可以在专用窗口内自行登录，工具不会读取登录凭据；浏览器自身可能在专用目录中保存网站数据，因此该目录不要分享。

关闭专用窗口后不反复新建，需手动重新打开。网站登录、验证码、视频播放、自动播放限制和下载确认由用户处理；本工具只负责显示窗口，不承诺自动播放。浏览器策略、权限或多个窗口造成无法可靠识别时停止操作，不按浏览器名称猜测窗口。

## 死亡惩罚与下载行为

- 使用本人 `scores.deaths` 的可靠累计值，重复轮询不增加次数，19→20 和直接跨过 20 都可触发。没有可靠累计数据时显示未知并禁用该次自动惩罚，不统计队友、不猜测次数。
- 达到门槛后，仍等待死亡延迟和灰屏确认；已经复活则等待下一次安全切出。本次优先原神官网，普通娱乐目标不会同时弹出。
- 先把本局触发记录原子写入 `runtime/penalty.json`，再打开页面并提交一次点击。暂停、模式切换、接口重连和同局重启不重复下载；下一局重新计数。状态保存异常时停止自动惩罚。
- 记录只保存带本地随机盐的身份摘要、进程摘要、对局时间、死亡数及触发状态，不保存明文玩家名。优先通过游戏进程创建时间和游戏时间判断同局；无法获取可靠进程身份、手动删除状态文件或极端环境变化时，不保证跨重启识别，详见验证记录。
- 从[原神官网](https://ys.mihoyo.com/)实时识别官方 PC 下载组件或当前官方 PC 链接，不硬编码安装包版本。只通过普通浏览器点击下载入口，不自动运行文件，不修改系统设置。
- 核查时入口重定向文件名为 `yuanshen_setup_20260924.exe`；仅核对了响应头，未获取文件。它是 Windows 安装入口，不能据此声称下载了完整游戏；可能需要后续安装启动器并下载游戏资源。[米哈游启动器官网](https://launcher.mihoyo.com/)也提供官方平台说明。
- 提交点击后只显示“已提交，未验证完成”；遇确认、拦截、验证或入口不可用时保留官网，不反复点击、不循环下载。切回游戏或切换模式会取消尚未执行的下载动作。

## 配置与结构

旧 `config.json` 自动迁移，保留玩家匹配、延迟、提前返回、阈值等已有参数；旧 Anki 路径迁移到默认目标。缺少新参数时使用默认值，未知已有字段保留。无效配置不会被静默覆盖。

完整默认例子见 [config.example.json](config.example.json)，自定义例子和字段说明见 [CONFIG.md](CONFIG.md)。

| 模块 | 职责 |
|---|---|
| `core.py` | 本人身份、快照、灰屏门槛、死亡状态机 |
| `study_flow.py` | 延迟、画面证据、后台回退、窗口动作协调 |
| `adapters.py` / `browser_target.py` | 统一目标接口、桌面与专用网页适配、复用预算 |
| `mode_config.py` / `mode_runtime.py` | 配置迁移、模式切换、目标优先级 |
| `penalty.py` / `state_store.py` | 本人累计死亡、本局一次触发、原子持久化与进程间锁 |
| `official_download.py` | 官方 PC 入口检查、单次点击与取消 |
| `native.py` / `capture.py` | Windows 窗口元数据及采样，不读写游戏内存 |
| `software_catalog.py` | 已安装桌面软件发现 |
