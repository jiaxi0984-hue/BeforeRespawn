## 保存规则

- 按功能保存最后相关版本，目录迁移和重命名不重复当作功能删除。仅归档历史中存在的实现，不为未实现的规划创建虚构代码。
- 原始源码、测试、配置示例和旧文档使用 `.txt` 后缀，避免被当前解释器、测试工具或配置读取器自动加载。图片保留原格式。
- [MANIFEST.json](MANIFEST.json) 记录原路径、来源提交、Git blob、字节数与 SHA-256；归档文件保持来源 blob 的原始字节。
- 当前源码 / 运行包显式排除 `archive/`，归档仅通过仓库访问。历史文档中的相对链接和测试结论属于当时版本。
- 不包含个人配置、日志、浏览器资料、凭据、依赖安装目录或本机运行状态。历史 Tk 界面仍用于当前回归测试，不属于已删除实现。
